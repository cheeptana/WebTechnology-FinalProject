# WebTechnology-FinalProject

## Introduction
This project is a web application developed as a final assignment for a Web Technology course. The application is primarily built using PHP and CSS.

## Development
The project was developed using the following tools and technologies:
- **PHP:** For server-side scripting and backend logic.
- **CSS:** For styling and layout of the web pages.
- **Local Server:** Tools like XAMPP or WAMP were used to run the PHP code and serve the web pages locally.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/cheeptana/WebTechnology-FinalProject.git
   ```
2. Navigate to the project directory:
   ```bash
   cd WebTechnology-FinalProject
   ```
3. Set up a local server (e.g., using XAMPP or WAMP) and place the project files in the server's root directory.

## Usage
- Start the local server.
- Open a web browser and navigate to `http://localhost/WebTechnology-FinalProject` to view the application.

## Features
- Dynamic web pages powered by PHP.
- Responsive design and layout using CSS.
- Structured project files with a focus on modularity and reuse.
